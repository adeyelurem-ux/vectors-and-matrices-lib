# A Messy Matrix Library

## This library is not safe for important projects. Please use this only for non-professional codebases for your own sake.

If the project you're building is important to you, **do not use this library**. It is unsafe and unergonomic. This is
simply an exercise in vector and matrix arithmetic, without using heavy dependencies.

However, if you'd like to use this in a sandbox and your project is just for fun, feel free. This **is not a professional
grade or well-optimised library**, use Eigen instead.
